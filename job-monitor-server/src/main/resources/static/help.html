    About

    Open source · built for Infor LN

    Know the moment a batch job fails, not the moment it's too late.

    Job Monitor watches your Infor LN ERP jobs and reports every run the instant it finishes — success, failure, or a breached SLA — so nobody has to comb through logs after the fact.

    How it fits together

    Three pieces, each doing one job well.

    Client

    job-monitor-client

    Register jobs and report each run's outcome back to the server.

    Server

    job-monitor-server · core · common

    Stores job history, evaluates alert rules, and sends the notification.

    Web UI

    job-monitor-web

    Visualizes status and history, and manages configuration.

    Modules

    A multi-module repo — pull in only what you need.

    job-monitor-clientRustModern CLI for registering jobs and pushing results.
    job-monitor-commonJavaShared models and utilities used across modules.
    job-monitor-coreJavaCore domain logic — job history, SLA rules, alert evaluation.
    job-monitor-serverJavaSpring Boot backend that stores history and sends notifications.
    job-monitor-webTypeScriptNext.js UI for status, history, and configuration.

    What it watches for you

    Live job status

    Every registered job reports RUNNING, SUCCESS, or FAILED as it happens, across every host and company you monitor.

    Failure & SLA alerts

    Set an alert rule once. Get an email the moment a job fails or runs past its expected duration — not the next morning.

    Execution history

    Start and end times for every run are kept, so average runtime and schedule drift are easy to spot at a glance.

    Error log search

    Filter historical error messages by job code and company to go straight to the run that broke.

    Multi-company, multi-host

    Follow the same job code across ERP companies and physical hosts from a single dashboard.

    Bring your own scheduler

    Push results from whatever launches your jobs today, using the CLI or the ERP integration contract directly.

    Talks to your ERP through one small contract

    Put a thin middleware in front of Infor LN and shape its responses to this format — the rest of Job Monitor doesn't need to change.
